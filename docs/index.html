  • latenC

    software systems prize, mountain madness 2026

    a vs code extension that calls out slow c++ and then proves it. it walks the tree-sitter ast, flags performance antipatterns (false sharing, list where a vector belongs, std::pow where a multiply belongs, virtual dispatch where crtp fits), explains why each one misses cache or blows allocations, and on click compiles real benchmarks on your machine at O2 instead of quoting big-o. header-only micro-benchmark harness with IQR outlier removal and p95/p99 tail latency; lock-free single-producer single-consumer ring buffer with acquire/release ordering, validated over 1M items under contention. zero runtime dependencies. c++ analyzing c++.

  • deepSWE eval harness

    private

    an ablation harness for an ai bug-fix pipeline over a private engineering-ticket corpus, built to answer "which layer failed" before anyone blames the model. contamination-controlled retrieval (self-exclusion, temporal cutoff, diff scrubbing), an eight-layer failure taxonomy (eval, model, state, tool, retrieval, context, index, prompt), preflight gates for paid runs, a run ledger that records what a solved ticket actually cost, and a structured human-verdict form. hybrid lexical plus semantic retrieval with reciprocal rank fusion, measured by ablation over a labeled benchmark (the hit-rate figure is being re-measured and is deliberately not quoted here); warm query latency went 12.4s to 1.4s with ranking proven identical on a 676-document corpus. it also caught its own circular-evaluation bug: a growth batch's gold labels had been chosen by the retrieval function under test, so the two populations now report separately and the flattering number cannot be quoted by accident.

    pythonsqliteembeddingsrrfablationeval methodology

  • differential verdict tool

    private

    "it works now" is not a verdict if you never saw it broken. this diffs a fix build against its own control across repeated automated runs of a large native c++ application, keyed on assert location rather than message text, with guards that refuse to claim: both arms on the same build is INVALID, fewer than two runs per arm is INDETERMINATE, flaky asserts within an arm are listed and excluded, never silently dropped. null-calibrated on byte-identical binaries across all 30 two-versus-two splits of five runs with zero spurious differences, and scenarios are ranked by cost to a trustworthy verdict (run time times the runs the measured flake rate demands), not by run time.

    pythona/b methodologyflake measurementnull calibration

  • runtime verification gate

    private

    a green build is not a verdict. the gate publishes an evidence contract before anyone spends a run (chosen from the ticket's own vocabulary: visual, behavioural, or runtime signal; behavioural evidence requires a baseline), records verdicts append-only in sqlite, and lets only a claimed pass have to earn it: eight blockers (missing evidence, framing mismatch, unchanged build, no build provenance, no expected versus observed, no repro steps, a dangling evidence pointer, no green presubmit) downgrade a pass to unknown with the reason on record. the case that motivated it passed six upstream gates while the feature under test was dead; the fix was settled by a counted log signature, not by pixels.

    pythonsqliteevidence contracts

  • receipts

    landing

    reliability ci for computer-use agents. run a task n times on isolated cloud browsers, verify every outcome independently of what the agent claims (final url, dom state, http side-effect probes against the real backend), and get a verdict you can defend. trial zero is a positive control that voids the run if the environment is unhealthy; verdicts are typed, and the interesting row is false_positive: the agent said it succeeded and the verifier disagreed. self-contained html report with per-trial screenshot timelines, session recordings, and a wilson 95% confidence interval; a ci gate that exits nonzero when the verified rate drops or the false-positive rate rises.
